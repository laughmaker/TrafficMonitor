# TrafficMonitor

一款原生 macOS 菜单栏流量监控应用。当前版本通过系统 `nettop` 获取进程级实时上传和下载数据，将辅助进程合并到所属应用，并在本机 SQLite 数据库中保存按分钟聚合的历史记录。

## 使用

启动应用后，菜单栏会显示实时上传和下载速率。点击菜单栏图标可以查看当前活跃进程，点击“打开流量监控”进入完整仪表盘。

仪表盘包含：

- 概览：今日、本周、本月总量，最近 7 天趋势和流量最高的应用。
- 历史：预设或自定义日期、分钟/小时/日/月聚合、热力图与 CSV/JSON 导出。
- 配额：日、周、账单周期及每个网络的独立配额、预测和通知。
- 实时：上下行速率曲线及当前活跃进程。
- 应用：搜索、最小流量过滤，并按总量、下载、上传或名称排序。
- 洞察：本地上传异常分析、上传最高应用和归属状态。
- 网络质量：延迟、丢包、DNS、Wi-Fi 状态、断网记录和手动下载测速。
- 设置：查看采样与存储方式，清空本机历史数据。

历史数据保存在 `~/Library/Application Support/TrafficMonitor/traffic.sqlite`，不会上传到服务器。

## 开发

```bash
swift test
swift run traffic-probe
xcodegen generate
open TrafficMonitor.xcodeproj
```

运行要求：macOS 14 或更高版本、完整 Xcode。

## 当前范围

- 菜单栏总上传/下载速率。
- 每 2 秒更新的进程流量列表。
- 概览、实时、应用排行和设置页面。
- SQLite 本地历史记录及最近 7 天统计。
- 完整历史范围查询、小时热力图和 CSV/JSON 导出。
- 菜单栏可切换实时速率、今日、本月和剩余配额。
- 可切换“按实际 App / 按网络出口 / 诊断模式”三种统计口径。
- 按当前 Wi-Fi/有线网络记录用量，并支持独立配额。
- 命令行进程沿父进程链归属到负责的图形 App。
- 本地上传异常检测和网络质量检测。
- 从 PID、进程名和已安装 `.app` 包中的辅助可执行文件解析真实应用图标。
- 统计全部网络接口，将 QQ、微信、豆包浏览器等 Helper 合并到所属应用。
- 排除 Clash、Mihomo、OpenVPN 等代理传输进程，避免本机代理链路重复计数。
- CSV 解析、单位换算和异常输入测试。
- 采集器异常退出后的退避重启。

历史记录从升级到 0.3.0 后开始使用新的应用归属方式；旧记录无法从代理总量中逆向拆分。网站归因、拦截和限速仍需要 Network Extension，是后续独立阶段。
